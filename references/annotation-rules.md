# 标注规则与措辞参考

## 字段含义

| 字段 | 写法 | 禁止内容 |
|---|---|---|
| 块批改结果 | `正确`、`半对` 或 `错误` | 自定义状态、模糊状态 |
| 块错因 | 短标签，例如“内分点坐标计算错误”“相似对应边混淆” | 空泛的“有问题”、人称代词、标准答案 |
| 块基础错因 | 问题性质和影响，例如“内分比例代入时坐标分配有误，点的位置偏离题设比例。” | “正确答案应为……”“应使用……” |
| 思路总结 | 直接概括过程和问题 | 给出标准解法或标准结果 |

## 状态判断

- `正确`：当前步骤的条件、公式、计算和逻辑与题意一致，且没有需要追溯的前序错误。
- `半对`：核心方向或部分计算成立，但存在局部符号、条件、表达或规范性问题，暂未使整段推导完全失效。
- `错误`：关键公式、条件、坐标、对应关系或推理依据错误，或者后续结论建立在前序错误上。
- 若某个后续步骤沿用前序错误，即使形式计算连贯，也应按任务规则判断其依据是否成立。
- 作答未展开、关键步骤跳过时，按“未完整论证”处理，不因后续存在形式计算而判为正确。

## 推荐句式

可使用：

- “公式结构混淆，后续推导失去依据。”
- “条件书写出现偏差，导致后续计算与题设不一致。”
- “前序坐标偏差继续影响向量表示，相关计算基础发生偏移。”
- “对应关系混用，后续比例关系难以成立。”
- “作答未展开，相关分析不完整。”
- “结论建立在前序推导偏差上，论证链条未闭合。”

避免使用：

- “学生写错了……”
- “正确答案应该是……”
- “应使用……公式。”
- “正确步骤为……”
- “最后答案虽然正确……”

## 连续块合并示例

如果块状态序列为：

```text
正确、正确、正确、半对、错误、错误、正确、正确
```

合并结果应为：

```text
正确（3块）｜半对（1块）｜错误（2块）｜正确（2块）
```

错误块的多个错因按照原顺序合并，不因合并而删除具体问题。结果不同的相邻块不能合并。

合并错因时的写法：

- 不同原因按原顺序用分号或换行连接：“内分点坐标计算错误；相似对应边混淆”。
- 完全重复的原因可只保留一条。
- 后续块若只是继承前序偏差，写“前序偏差继续影响……”，不要把前序原因重复堆砌成新的独立错误。
